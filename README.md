一个针对 .NET 程序集的 **IL 定点补丁工具**，用于研究 **编译期常量折叠** 对二进制结构的影响，以及演示如何在 .NET 元数据层面进行安全的方法体替换。

## 一、这个项目研究什么

现代编译器（VB.NET、C#）会对 `Const` 常量做**内联 + 死代码消除**。当代码中写出：

```vb
Public Const FeatureEnabled As Boolean = False

If FeatureEnabled Then
    DoSomething()   ' 编译后这段 IL 完全不存在
End If
```

生成的程序集里**不会留下任何判断痕迹**：既没有字段读取指令，也没有那个分支的字节码。这意味着：

- 修改字段的常量值 -> 无效（没人读它）
- 修改跳转目标 -> 无效（目标地址不存在）

要理解这类结构，必须从**未折叠的旧版本**中取回原始方法体，再在元数据层面做指令重映射与重写。

本项目就是这一过程的完整、可复现实现。

---

## 二、工具能做什么

| 能力 | 说明 |
|---|---|
| 哈希校验 | 强制验证输入与供体的 SHA256，不匹配直接拒绝 |
| 方法体移植 | 复制方法体，含分支目标与异常处理器的完整重映射 |
| 定点指令修改 | 原地替换少量 IL 指令，不触碰其他字节 |
| 安全写回 | 用 dnlib 重新计算并校验 MaxStack，栈不平衡直接报错 |
| 结构保真 | 保留原有资源、字符串池、程序集版本与 MVID |

## 三、技术栈与原理

- 语言：C# (.NET Framework 4.8)
- 核心库：dnlib 4.5.0 (MIT)
- 方法：直接读写 ECMA-335 元数据与方法体，**不重新编译整个程序集**

### 为什么不用别的方案

| 方案 | 结论 |
|---|---|
| Mono.Cecil | 写回时强制解析所有外部引用，单文件程序集缺依赖时失败 |
| ILDASM 到 ILASM 全量往返 | 整文件重汇编，NaN 字面量与带引号枚举字段触发语法错误 |
| dnlib 定点修改 | 不解析无关依赖，只改目标方法体 |

详细踩坑记录见 `补丁思路与踩坑记录.md`。

## 五、使用前提

使用者需**自行准备**两个由官方渠道获取的程序集副本：

- 一个**目标版本**
- 一个**供体版本**（未经过常量折叠的旧版本）

本仓库不提供、不镜像、不引导获取上述文件。

工具内置 SHA256 白名单，只接受与预期完全一致的输入；其它版本会被直接拒绝。这是有意的安全设计。
